Why convert PNG to WebP?

WebP is designed for efficient image delivery on the web and can produce smaller files than PNG in many situations.

Converting PNG images to WebP can therefore be useful when preparing graphics and other images for websites where file size and loading performance matter.

WebP also supports transparency, making it useful for many images that would otherwise be stored as PNG.
