Tips for reducing JPG file size

Start around 80% A moderate quality setting can be a useful starting point for balancing size and appearance.
Check the result Compression affects different images in different ways, so inspect the output before using it.
Use lower quality when size matters Lower quality settings generally produce smaller JPG files.
Avoid unnecessary recompression Repeated lossy JPEG compression can reduce image quality over time.
