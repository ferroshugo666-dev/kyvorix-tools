Why convert PNG to WebP?

WebP is designed for efficient image delivery on the web and can produce smaller files than PNG in many situations.

Converting PNG images to WebP can help reduce image file sizes when preparing graphics, screenshots and other images for websites.

WebP supports transparency, making it particularly useful for logos, icons and graphics that would otherwise need to remain in PNG format.
